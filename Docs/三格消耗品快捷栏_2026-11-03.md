# 三格消耗品快捷栏

2026-11-03用户明确新增：三格快捷栏用于方便使用消耗品，背包页同样显示，拾取消耗品时有空格自动填入。后续要求检查火把这类可调控状态的消耗品表现。

## 本轮实现

- 探索画面显示三格，背包及角色装备页显示相同绑定。探索中点击或按1／2／3使用；背包页可点击使用。
- 每格关联一种背包消耗品，数量合计所有背包堆叠；不增加额外库存或背包容量。同类不重复占格。拾取成功、商人购买成功时填空位；三格已满则只入背包。
- 背包消耗品可拖到任意快捷格替换绑定，右键移除绑定，不丢弃物品。背包整理不会改变绑定；最后一件用完或丢掉后清空。空位不会每帧自动塞入未绑定的旧库存。
- 火把首次点燃时消耗一根库存，快捷格转为“燃烧中”，显示剩余步数；点击／数字键切换开关。2026-11-03后续用户修订：手动熄灭保留剩余耐久，可以再次点燃同一根，不消耗备用库存；无备用时仍保留这根有耐久的火把快捷格。耐久耗尽后，有备用则显示可点燃，无备用则清空。燃烧中的快捷格右键不会移除，熄灭后可移除绑定，火把仍可由探索底栏开关恢复。
- 满血药剂、当前不可重复使用的增益、已关闭的消耗品功能沿用现有使用条件；快捷栏不开放战斗消耗品，也不突破暂停／设置／商店／放大小地图的输入限制。
- `RunData.quickSlots` 保存三种物品类别，-1为空；随本局存档恢复。旧存档缺少字段时按背包顺序填入最多三种已有消耗品，不增发物品、不改变地图。
