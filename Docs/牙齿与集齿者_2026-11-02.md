# 牙齿与集齿者（2026-11-02）

## 已明确规则

- 新增单局货币“牙齿”，击败怪物获得，不占背包格。
- 可向商人“集齿者”购买商品，本轮只出售消耗品。
- 用户授权试配价格；商人随机分布，不能与怪物相邻。实现按周围八格均无怪物处理。
- 后续明确数量限制：每层至多1名，任意连续5层至少2名（滑动窗口，包括跨分段窗口）。

## 当前原型试配

| 项目 | 配置 |
|---|---|
| 普通怪胜利 | 3颗牙齿 |
| 首领胜利 | 10颗牙齿 |
| 治疗药剂 | 5颗／件，探索使用恢复20生命 |

| 商人分布 | 每层0或1名，任意连续5层至少2名；首领层不生成但计入窗口；楼层及位置随种子确定 |
| 库存 | 暂不限库存，每次购买1件 |

产出、价格、库存以及普通层50%的初始生成概率为可调的原型试配，非完整版定案。数量上限及连续5层下限是用户明确规则；先随机选择普通层，再对所有不足2名的滑动窗口随机补足，首领层保持不生成。当前8层的1—5、2—6、3—7、4—8均验收；5层兼容规格也满足1—5的数量要求。消耗品沿用探索使用方式，不增加战斗内直接使用入口。商品成功购买后进入背包，按既有同类20件堆叠规则占格。

## 操作与安全边界

探索HUD显示牙齿余额。发现商人后可左键寻路接近并交易，或在四向相邻格按E交易；点击离开或Esc关闭。集齿者沿用已有商人像素素材，阻挡其所在格。商店显示商品用途、价格、余额，以及牙齿不足或背包已满的禁用原因。

生成完成后以商人和箱袋为永久障碍检查所有剩余地面连通、楼梯及箱袋交互位可达，并继续验证原有镇守入口约束。商人不得与出生点、箱袋或怪物重叠，不与任何怪物八向相邻；生成时不删除或挪动怪物来放商人。

胜利按敌人的`defeated`标记仅结算一次，即使满包仍获得牙齿。购买前检查范围、商品、余额及背包容量；失败不扣牙齿、不生成物品、不推进物品ID。背包无空格但同类堆叠未满时仍可购买。

牙齿随本局手动存档保存，暂时存档回城不会清除。正式结束或失败结算时不进入仓库、不换成城镇金币；新局从0开始。取消主动离局结算仍保留原余额。购入的消耗品继续遵守现有物品带出规则。

旧存档缺失余额时为0，不追补已击败怪物的牙齿；后续新胜利正常发放。不向旧地图补商人、不移动现有对象或重新生成地图；包括上一版逐层商人的快照也原样保留。新数量分布仅用于新局。
