# 背包装备、网格移动与三属性星图原型

## 2026-11-02用户最终明确规则

- 武器只有整件剑盾，没有独立的剑。剑盾不拆为剑和盾。
- 装备栏由1件武器、4件护甲（按参考图为头部、胸甲、护手、靴子）、最多3件戒指/饰品组成，共8个独立槽位。采用人物居中、槽位环绕、背包在右的布局。
- 背包和装备页按独立格显示；装备可存入背包、从背包拖动。
- 角色按网格移动；同时按住多个方向时，使用最先按下且仍按住的方向。
- 新局取消副属性选择，同时取消副属性及每点1%最终伤害加成。三属性通过装备修正和天赋发挥作用。
- 天赋采用力量、敏捷、智慧三区星图。解锁即点亮、激活生效；点亮需要满足条件（含前置天赋激活）并消耗天赋点。回撤返还天赋点。允许少量测试点数。

以上后续修订优先于属性v1、最小模型范围及旧说明中的冲突条目。

## 装备与背包实现

背包保留20格，装备每件1格；材料/消耗品沿用原堆叠规则。武器、头部、胸甲、护手、靴子、戒指1/2/3均有独立拖放目标；戒指共用物品类型，各实例保存实际穿戴槽。拖入匹配槽换装，旧装备回到来源背包格；从穿戴槽拖回空格卸下，拖到同部位装备可交换；背包内可交换整格内容。拖到界外取消，丢弃需显式确认。第四枚戒指只能替换已有戒指，不能形成第四个生效槽。

现有铁剑/迅捷剑/铭文剑/精制长剑的存档ID保留，当前定义和名称统一为铁制/迅捷/铭文/精制剑盾。出生基础能力显示为训练剑盾。旧Sword枚举和独立木盾只用于旧档兼容，不进入新局掉落；新局无副手槽。剑盾始终为一个武器定义、一个实例、一个武器槽，带出只算一件。

新增原型试配：制式剑盾（基础ATK2、力量修正60%、防御1）、皮盔（生命+2）、皮护手（力量+1）、皮靴（敏捷+1）、铜戒指（智慧+1）。新增装备每件1格、常见品质。既有剑盾变体保留原攻击与修正数值，不凭类型统一增加防御。第二至四层箱池加入新增部件/戒指，制式剑盾替代原木盾位置；新增部件及戒指各权重3，其他原权重保留。首层武器池保留三种现有剑盾变体。数值与权重均为测试配置，可调整，不是完整版定案。

图标从项目Equipment.aseprite中原样取图，通过Unity MCP导入与配置；保留整件剑盾图，不将护手图当作武器。用户参考图只提供部件/布局依据，不自动引入套装效果或其他品质规则。

## 网格移动

洞窟、城镇、公会均按单格移动；试配速率保持洞窟3格/秒、城镇4格/秒。键盘和鼠标寻路停在格心，不斜走、不停半格。按输入事件顺序记录方向，最先按键即使被墙阻挡也不采用后按方向；松开后由仍按住的下一方向接续。WASD、方向键均支持。同一事件内完全同时按下时固定顺序为W、上、S、下、A、左、D、右。

### 同方向连续移动修复

后续用户要求修复连续输入的平滑移动：移除“瞬移一格后等待”的计时方式。逻辑目标及存档仍是格心，显示位置在相邻格心之间匀速推进；每帧未用完的移动距离接续到下一段，同方向长按跨格不暂停、不逐格缓入缓出。洞窟速度3格/秒、城镇4格/秒。鼠标寻路使用同一推进方式。松键后完成当前格，方向变化在格心执行；前按方向优先和碰撞规则保留。相邻交互等待人物到达格心，避免显示位置尚未靠近时提前触发。

## 三属性与天赋点

新局secondary=None、伤害乘区恒为1，不再授予旧副属性每3级成长；力量等级成长和生命成长保留。伤害取整、防御和格挡顺序沿用既有规则。

星图保留已有节点效果、公会、声望与前置等级条件。学习不再扣金币，每级暂定1天赋点，初始给3点测试额度。骑士誓言为免费的职业根节点；其他节点可点亮或逐级回撤，也可一键回撤全部。单节点回撤如会使已激活后续节点失去前置，提示先回撤对应后续节点；不会静默撤销其他节点。每次点亮/回撤均立即保存。当前尚无正式的天赋点产出流程。

新增智慧训练：每级智慧+1，最多3级，根节点前置、公会1级，每级1点，均为首轮试配。点亮的天赋即为激活，无独立解锁/携带开关；灰色表示条件或点数未满足、白色表示可点亮、绿色表示已点亮生效。选中节点及其前置路径用青色突出。连线按前置关系分段走线，避开文字且不交叉。

天赋对角色的应用继续遵守出发快照：城镇中点亮/回撤立即改变激活状态，供下一局出发使用；不改写已出发局的快照。

## 存档兼容

旧局保留副属性、倍率、成长、地图和天赋快照，不追补新装备或天赋。旧三槽档如已有独立木盾，仅显示兼容卸下入口；新局严格8槽。穿戴位置通过物品实例保存，戒指1/2/3不因同种物品而合并。

旧7节点城镇档在内存中扩成8节点，智慧为0；生成.pre-star-talents.bak。仓库v3迁移天赋点时生成.pre-talent-points.bak，保留旧激活等级和金币，额外提供3个测试可用点，点数总额=旧投入等级数+3；不会重复授予。仓库v4向v5迁移新增物品计数长度时生成.pre-eight-slots.bak。原文件在正常保存操作之前保持原样。
