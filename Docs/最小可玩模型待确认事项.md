- 随机地形和必要门验收通过，生成次数有上限。

- 视野、迷雾、遮挡墙半透明与对象显示一致。
- 卡牌结算、敌人行动、经验和升级选牌按已确认顺序运行。
- 背包堆叠、部分拾取、丢弃再拾取、回血和首次获取记录正确。
- 主动、失败及胜利结算容量与入库正确，取消和中断恢复不重复入库。
- 重启后恢复原地图、玩家、对象与随机进度；死亡或正式结束后旧探索存档失效。
- 全部5张图能完成短流程，新局重置本局成长并保留仓库。
