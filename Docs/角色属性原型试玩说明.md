# 角色属性原型试玩说明

日期：2026-10-25。对应《角色属性与装备系统完整原型设计_v1.0.md》。

> 最新源码修订：攻击伤害四舍五入为整数，卡面仅显示最终伤害及抽牌等必要效果。本次编辑器验证与运行包更新尚待通过Unity MCP执行；现有Windows包和截图仍为上一版。

## 启动与本局选择

Unity打开 `Assets/Scenes/WorldMap.unity` 或原有 `MagicCavePrototype.unity` 后Play。前往洞窟传送门，点击“开始新局”，明确选择“敏捷”或“智慧”作为副属性，再点击“开始探索”。取消出发不会覆盖原有存档。

角色为战士公会骑士，主属性力量。无天赋时初始力量10、敏捷5、智慧5、生命60；默认训练剑实际ATK6。两种副属性起始均提供5%最终伤害，后续有效副属性每点额外贡献1%。继续存档保留原选择与出发天赋。已有属性版存档的副属性系数会兼容更新为1%，其余属性和进度保持。

Windows属性版输出位置为 `Builds/WindowsAttributes/MagicCaveGame.exe`；分享时保留整个WindowsAttributes文件夹。原WindowsPixel目录保留旧版本。

## 操作

| 入口 | 用法 |
|---|---|
| C／角色按钮 | 查看力量、敏捷、智慧、主副属性、实际ATK、武器修正和增益来源 |
| B／背包 | 使用精华或药剂；点击装备的“装备/对比”进入角色面板 |
| 角色面板的背包装备列表 | 选择装备查看ATK、打击、重击、属性及生命上限的前后变化，点击“确认替换” |
| 装备槽右侧“卸下” | 需要背包空格；满包仍可直接交换装备 |
| Tab／卡组 | 查看当前属性计算后的卡牌数值 |
| Esc | 关闭角色、背包、卡组或出发面板；探索／战斗中打开暂停 |

换装和使用物品限探索阶段。角色面板打开时停止地图移动。已穿装备不占20格背包，但每件都占一个带出名额。

## 可验证的构筑

首图提供一件常见武器和一件增益物品，后续常规地图每图提供一件装备和一件增益，仍需遵守物品镇守规则。

- 铁剑偏力量修正；迅捷剑同时有力量和敏捷修正；铭文剑同时有力量和智慧修正。初始三属性下三者ATK均为8。
- 智慧副属性配铭文剑时，智慧精华既提高武器ATK，也提高最终伤害倍率。
- 木盾增加敏捷；启迪皮甲增加智慧及生命上限；铁甲每段物理伤害减免1。
- 力量／敏捷／智慧精华各增加对应属性1点，持续本局；新局清除。
- 强攻药剂使接下来两场战斗力量＋2，界面显示剩余场次；切图、等待、存档不扣场次。剩余2场时不能重复消耗，剩余1场时再用刷新到2场。
- 每级最大生命＋4，偶数等级力量＋1，到达3的倍数等级已选副属性＋1，同时仍可三选一选牌或跳过。

提高生命上限不会恢复当前生命。换装降低上限时超出部分截断，反复穿脱不会治疗。

## 卡面与计算

```text
实际ATK＝武器基础ATK＋力量×力量修正＋敏捷×敏捷修正＋智慧×智慧修正
副属性倍率＝1＋当前有效副属性×0.01
每段伤害＝（实际ATK×卡牌倍率＋战意固定加成）×副属性倍率
然后逐段减物理防御、抵消格挡、扣生命
```

出生训练剑、无天赋时：打击4；重击9；连击每段2、共两段；防御获得10格挡。卡面仅显示最终整数伤害，移除ATK倍率、副属性加成和重复的预计生命损失；迅击抽牌、盾击不消耗格挡等必要效果保留。

盾击按当前格挡计算，再乘副属性倍率，不读取武器ATK、不消耗自身格挡。战意在卡牌倍率之后、副属性倍率之前提供每段＋2。

伤害计算使用decimal中间量，每段在所有输出加成计算后只取整一次，四舍五入到整数：4.45→4，4.5→5，4.4994→4。卡面与实际伤害使用同一结果；已有存档中的小数生命和格挡仍兼容。

## 存档与仓库

继续沿用 `Application.persistentDataPath/magic-cave-prototype`。新格式保存整局角色／武器配置快照、三属性来源、装备、已选副属性和药剂剩余次数，本次1%修订会显式更新已有属性版存档的副属性系数，并备份到 `.pre-secondary-1pct.bak`；其余配置继续使用原快照。

旧探索存档继续按原有固定伤害与选牌规则游玩，不自动发放三属性成长或副属性加成；开始新局进入新版。首次覆盖旧格式时生成 `.pre-attributes.bak` 备份。仓库格式升级到v3，保留原材料数量、天赋、金币、声望与结算记录。

结算支持所有新物品和已穿装备，主动最多10件、失败最多5件。新增装备按实例存入仓库；仓库“装备与新增物品”分页可查看。新物品暂不出售、捐赠或带入新局。

## 配置和验证入口

- `Assets/MagicCavePrototype/Resources/CharacterRules.asset`：Inspector编辑角色初值、成长、武器基础ATK、三项修正及卡牌倍率；百分比使用基点，10000表示100%、15000表示150%。每个新局复制独立快照。
- Unity菜单 `Magic Cave → Build Windows Attribute Prototype`：构建以世界地图为入口的Windows属性版。
- 自动测试位于 `CharacterAttributeTests.cs` 以及原有规则／运行测试。验证使用独立临时存档，不给用户仓库添加测试物品。
- 本轮结果、截图与构建日志位于 `Captures/CharacterAttributes`。图形交互测试需在正常图形编辑器中执行；批处理模式不会完整驱动IMGUI绘制与输入。

命令行参数 `-prototypeStorage <绝对目录>` 可为独立运行包指定测试存档位置，方便启动检查，不影响默认用户存档。
