# 鼠标轮盘与小地图试验

2026-11-03，按用户要求试验方向轮盘，并在洞窟右上角加入点击可达地块寻路的小地图。不改变地图生成、存档结构、障碍、迷雾揭示及火把计步规则。

- 城镇、公会与洞窟地图：左键单击保留寻路／交互；洞窟单击在松开时提交。
- 后续修订：轮盘默认常驻右下角。在默认轮盘的方向区域按住，立即沿该方向连续走格，以固定轮盘中心判断方向，松手后归中。在地图操作区任意位置长按0.25秒，轮盘临时移到按下位置；松开后恢复右下角。按钮、背包装备拖拽、小地图及放大地图保留各自输入，避免误触。参考用户提出的《王者荣耀》呼出方式，位置按用户要求采用右下角。
- 同时保留拖动超过18个界面单位直接启动轮盘；回到中心12个单位内停止输入。对角线切换加入1.25倍方向滞回，减少抖动。时间、距离及滞回参数均为手感试配。
- 角色仍逐格移动，拖动距离不改变速度。松开后完成当前格，不开始下一格；碰到障碍停止，不自动绕路。键盘方向优先并取消鼠标操作。
- 轮盘拖动松开不再触发点击寻路或界面按钮。面板、战斗、切图、切换城镇／公会及失去焦点会清除轮盘状态。装备拖拽不触发轮盘。
- 洞窟小地图位于右上角，使用与主地图一致的方向和揭示状态。未揭示区域隐藏；白色角色、红色存活怪物、金色有物品容器、棕色空容器、绿色门、紫色集齿者，青色显示当前路径。
- 小地图单击已揭示的可通行地面后，通过现有寻路器沿已揭示路线移动。墙、怪物、容器、商人、门及未揭示地块不作为移动终点；不自动战斗、开箱、过门或破墙。没有已揭示路线时提示无法到达。
- 小地图区域屏蔽底层场景鼠标输入；在其中按住拖动不启动方向轮盘。
- 小地图标题旁“放大”展开居中的大地图；点击“收起”或按Esc返回。放大时阻止底层移动及界面输入；点击已揭示且可达地面后自动收起并开始寻路。不可通行或没有已揭示路线的地块不会关闭地图或提交移动。

实现：`PrototypeNavigation.cs`，接入 `PrototypeGame.cs`、`PrototypeInterface.cs` 与 `PrototypeTown.cs`。

验证：通过 Unity MCP 确认目标项目、刷新导入与编译，Console 编译错误为0。两轮 PlayMode 共9次执行、7个不同用例全部通过：轮盘方向滞回／中心停止／释放不误点击，键盘接管与背包取消，城镇轮盘，小地图可达／不可达／迷雾／防穿透，以及原有键盘锁格、破墙、火把计步。检查了测试地图运行截图（`Captures/Navigation/`）；轮盘手感仍需实际试玩反馈，本次未构建运行包。

后续修订验证：通过 MCP 编译检查及5项 PlayMode 测试，包括默认轮盘立即移动、0.25秒长按原地呼出与松手归位、放大地图阻止底层移动／点击、Esc与收起按钮、放大坐标寻路，及原轮盘／小地图／城镇回归。检查了默认轮盘、长按轮盘和放大地图截图，Console错误为0。
