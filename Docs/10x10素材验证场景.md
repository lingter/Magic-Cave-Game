# 10×10素材验证场景

场景：`Assets/Scenes/ArtValidation10x10.unity`。

在 Unity 中打开场景即可查看完整搭建结果，按 Play 验证操作。采用固定正交镜头，地图总尺寸为10列×10行，包含最外围一圈墙；每格1单位，素材16 PPU、Point过滤、无压缩、无MipMap。运行时根据窗口大小选择整数像素放大倍数。地图不随机生成，不使用种子或存档。

## 操作

| 操作 | 效果 |
|---|---|
| WASD / 方向键 | 连续移动，键盘输入取消点击寻路 |
| 左键地面 | 按四方向网格寻路 |
| E | 与附近商人、宝箱、袋子、敌人、尖刺或楼梯交互 |
| V / 顶部按钮 | 切换美术与白模显示，沿用同一份地图与碰撞规则 |
| G / 顶部按钮 | 切换网格线 |
| R / 顶部按钮 | 重置玩家、物件和显示状态 |

摄像机固定显示整张地图，不旋转、不跟随、不允许缩放，以便比较同一位置的美术和白模。玩家使用新增的上、下、左右方向素材。

## 重点检查

1. 上下两条水平墙的砖纹方向、四个外角以及T形连接是否连续。
2. 左侧出生点通道、右侧隔墙附近的一格宽通道是否可以正常移动，不能穿过墙角。
3. 靠近商人、箱子、补给袋和敌人时是否被阻挡；拾取箱子或袋子后是否可以进入原格。玩家不透明图像为0.75×0.75格，碰撞体为0.8×0.8格，靠近实物时保留小幅间隔，一格宽通道仍可通行。
4. 人物站在物件上方或下方时，前后遮挡顺序是否正确；尖刺和楼梯始终贴地。
5. 切换白模和网格后，逻辑占格、通道和交互范围是否与美术对应。

## 资源与维护

- 原始素材保留在 `Assets/ART Assets`；导出的PNG位于 `Assets/ArtValidation/Sprites`。
- 如更新原始素材，在项目根目录运行 `python Tools/export_validation_sprites.py`，需要Pillow。
- 重新生成场景：`Magic Cave → Art Validation → Create or Rebuild 10x10 Scene`。此操作会用固定布局重建验证场景，重建前保存手动修改。
- 运行自动验证：`Magic Cave → Art Validation → Run PlayMode Checks`。
- 三张编辑器渲染预览、场景结构验收和PlayMode结果位于 `Captures/ArtValidation10x10`。PlayMode执行后还会生成包含操作栏的实际运行截图。

原型场景和正式运行包使用各自入口，本验证场景独立存在。
