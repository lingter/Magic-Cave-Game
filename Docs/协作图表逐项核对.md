## 9. 基础回合与出牌资源

策划第3、6页与设计第7页为同一个回合图：

```text
每回合根据速度值决定先后手
→ 玩家回合开始
→ 玩家抽取若干牌、回复若干行动点
→ 玩家出牌
→ 玩家回合结束
→ 敌人回合开始
→ 敌人行动
→ 敌人回合结束
→ 回到速度判定
```

图已定义速度用途和行动点回复时机；问题是只有玩家先手的一条路，缺敌人先手、同速和多敌排序。抽牌量、行动点初始值／回复量／上限、余量是否保留、出牌次数恢复均未给出完整值或规则。图也没有弃牌、状态结算和战斗结束分支。

设计第8页资源图：出牌资源是出牌所需代价，分行动点与出牌次数；行动点又关联行动点上限、每回合回复数量。策划第6—7页补充不同牌行动点费用可不同，每张打出的牌都消耗一次可出牌数。不能把速度、行动点、出牌次数视为同一变量。

## 12. 逃跑流程

来源：设计第10页。在抽牌／回复行动点后加入“按下逃跑？”判断：“否”进入玩家出牌，再经玩家回合结束进入敌方回合；“是”直接进入敌人回合开始。后续仍是敌人行动、结束、再次按速度判断。

**图中没有逃跑成功、脱离战斗或返回地图的出口。** 按图执行只会跳过出牌；“是”还绕过玩家回合结束节点。可能的意图包括先承受敌方行动再脱战、概率逃跑或其他设计，材料不足以决定采用哪一种。

## 13. 删除线与占位的完整核对

策划第4页“行为系统”、基础行为与触发链路有删除线；第10页“相邻空格填满敌人的多敌伏击”和“行动轴回合制”有删除线。保留在奇思妙想中的内容是理智、更多炸弹交互、洞察、无火把伏击、力量／敏捷／智力事件判定，不应据此恢复旧删除方案。

地理背景、牌堆小节仍无具体规则；状态牌／诅咒牌仍写“懂得都懂”；酒馆老板、顾客与酒馆仍待设计；天赋与考古学家图中的省略号仍是占位。相比之下，整体战斗规则、回合、出牌资源、数值计算、物品解锁、逃跑都**有图示内容**，不能再描述为原文只有空标题。
