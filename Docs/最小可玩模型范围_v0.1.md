# 最小可玩模型范围

> 版本：v0.1  
> 日期：2026-10-18\
> 状态：最小模型玩法、范围及交付方式已确认，独立试玩场景已实现。  
> 地图设计基准：`D:/Users/lingter/Downloads/地图系统设计文档_v0.10.md`。  
> 本文件记录最小模型的阶段规则，不覆盖完整版地图设计。尚未确认的问题见同目录《最小可玩模型待确认事项.md》。

## 1. 模型要验证的闭环

探索 → 主动遭遇敌人 → 卡牌战斗 → 结算经验 → 升级选牌 → 后续战斗使用构筑后的卡组。

战斗胜利与失败均发放经验。生命值降至0时，整局游戏失败并结束，不返回探索继续游玩。失败获得5点经验，计入本局结果统计，直接进入失败结算，不再弹出选牌。等级与卡组不继承到新局。

模型胜利条件：击败第5张地图的首领，通过返回门选择“结束游戏”，完成带出物品结算后，正式结束本局并记为胜利。仅击败首领或选择存档均不结算本局胜利。

## 2. 已确认：视角与探索操作

- 采用类似《明日方舟》的2.5D俯视表现。
- 摄像机随人物移动。
- 地图由格子构成，人物自由连续移动，不要求停在格子中心。
- 同时支持 WASD／方向键控制，以及鼠标点击地面自动寻路。
- 键盘移动立即取消当前点击寻路。
- 键盘按屏幕方向移动，允许斜向输入，斜向不加速；移动速度为每秒3格。
- 摄像机采用透视镜头，俯角50°，垂直视场角35°；角色位于画面中央，跟随距离10单位，平滑时间0.1秒。
- 镜头朝向固定，水平角为0°，不允许水平旋转；鼠标中键拖动与 `Shift+R` / `Shift+T` 不控制镜头。俯角与距离保持固定，暂缓缩放。
- 切图、战后返回、读档和新局均使用相同固定朝向，镜头对准角色。WASD／方向键始终按屏幕方向移动，名称标签朝向镜头。旧存档中的镜头方位会被忽略。
- 遮挡人物的已揭示墙临时半透明，碰撞保留，迷雾继续遮住未揭示内容。
- 摄像机拍到的范围不扩大逻辑视野。

### 2.1 探索操作与交互

| 项目 | 规则 |
|---|---|
| 点击地面 | 左键点击已揭示地面寻路，路径只经过已揭示的可行走区域 |
| 点击对象 | 左键点击可见敌人、物品或门，距离不足时先自动接近，再执行交互 |
| 交互范围 | 物品可同格或四方向相邻交互；敌人与门从四方向相邻的可站立格交互，不能隔墙交互 |
| 键盘交互 | `E`操作当前高亮对象；范围内最近的对象自动高亮，鼠标指向的近处对象优先 |
| 破墙 | 右键点击已揭示内部墙，接近到四方向相邻格后，一次破坏一格，变为 `Ground` |
| 前进门 | 点击或按 `E`交互后进入下一张地图，走到门旁不会自动切图 |
| 返回门 | 点击或按 `E`打开“存档／结束游戏”选择 |
| 背包与卡组 | `B`打开背包，`Tab`查看卡组；打开时停止探索移动 |
| 取消操作 | 键盘移动或点击新目标，取消此前寻路及待执行交互 |

- 寻路不自动破墙；目标不可达时提示“无法到达”，角色留在当前位置。
- 点击界面按钮不会同时触发地图操作。

### 2.2 第一版画面、探索界面与暂停

- 新建独立试玩场景，现有《明日方舟》静态场景作为视觉参考。
- 角色与敌人使用简单3D占位模型，通过形状、颜色和名称区分。
- 地形使用简单3D地块，门、物品与可交互对象具有清晰标识和高亮。
- 探索界面显示地图序号、生命、等级、经验进度、背包占用，以及当前对象的操作提示。
- 卡牌界面显示名称、费用和效果，第一版采用简单排版。
- 正式美术、配音、音乐与复杂特效后移，保留必要高亮与数值反馈。
- `Esc`优先关闭背包或卡组面板，否则打开暂停菜单。
- 暂停时停止探索移动和战斗推进。
- 暂停菜单提供“继续游戏”“返回局外”“退出游戏”。
- 返回局外或退出前提示未保存进度，不额外存档、不执行物品结算，下次按最近手动存档继续；没有存档则只能开始新局。
- 手动存档与主动带出结算仍通过返回门进行。

## 3. 已确认：迷雾与敌人交互

- 第一版保留基础迷雾。
- 地块情报继续使用地图文档的“未揭示／已揭示”两种状态。
- 照明与理智系统在本阶段暂缓。
- 敌人进入视野即可被发现，不再以玩家处于照明状态为前提。
- 发现敌人后，由玩家主动点击或交互发起战斗。
- 探索中的敌人保持静止，不追踪玩家，具有实体体积；存活敌人所在格禁止进入，键盘移动与鼠标寻路都遵守这一限制。点击敌人后停在四方向相邻的可站立格进入战斗，战胜后该格恢复通行。玩家可绕行或破墙选择路线，不要求清图才能使用前进门。
- 点击敌人后先自动接近至交互距离，再进入战斗。
- 战斗使用独立界面，胜利后返回探索位置；若首领战后新生成的返回门与玩家脚下或角色体积重叠，将玩家移到最近的可站立位置，保证能继续移动、存档与结束本局。生命值降至0时结束整局，进入失败流程。
- 交互范围与接近取消规则见第2.1节；视野和揭示细节见第3.1节。

### 3.1 视野与显示

| 项目 | 规则 |
|---|---|
| 角色所在格 | 根据实际位置判定，不要求停在格子中心 |
| 基础视野 | 曼哈顿距离≤1，即所在格及上、下、左、右四格 |
| 更新时机 | 进入新格、破墙、切图和读档时立即刷新 |
| 地块揭示 | 进入视野后永久揭示，仍只有未揭示／已揭示两种状态 |
| 敌人 | 首次发现后持续显示，离开当前视野不隐藏，仍占据其所在格；未发现敌人仍由迷雾遮住，战胜后移除 |
| 地面物品 | 首次发现后持续显示，离开当前视野不隐藏；只有玩家操作导致数量或状态变化时更新。未发现物品仍由迷雾遮住 |
| 门 | 被揭示后持续显示，离开当前视野也能看见 |
| 首领地图 | 场地与对象全部可见，不使用迷雾 |

## 4. 已确认：隐藏门与破墙

- 第一版保留破墙寻找隐藏前进门的玩法。
- 隐藏门四方向相邻的墙体，探索揭示后显示金黄色高亮，提示门的位置；鼠标指向时显示“门的线索”。未揭示墙体的高亮不穿透迷雾，门本身仍需破墙并进入视野后揭示。高亮随已揭示墙体持续保留，墙被破坏后不再显示；墙体遮挡人物时仍按原规则半透明。
- 第一版破墙暂不消耗资源。
- 门候选继续遵循地图文档的内部墙格、四面环墙及 `Ground → Wall → 候选门格` 条件。
- 任意两个常规地图门之间的曼哈顿距离至少为3。
- 所有内部普通墙可破坏，最外层墙不能；第一版不设墙体耐久，一次破坏一格，不消耗资源。
- 右键点击已揭示内部墙，自动接近到四方向相邻格后破坏，破坏后变为 `Ground`。
- 隐藏前进门已确认保留；常规返回门仅安排在第3张地图中，遵循常规隐藏门规则。第5张首领地图在击败首领后出现返回门。第一版暂缓事件门与事件地图。

## 5. 已确认：本局成长与选牌

- 角色具有等级与经验。
- 本阶段经验仅来自战斗，在战斗结束时发放，胜利与失败均可获得。
- 本阶段额外获得卡牌的途径仅为升级选牌，不设置其他获取来源。
- 每次升级随机提供三张候选卡，玩家选择其中一张加入本局卡组，也可跳过。
- 等级与构筑后的卡组仅在本局成长，开始新局时重置。
- 起始等级为1级，经验为0；普通战斗胜利获得10点经验，首领战胜利获得30点经验，战斗失败获得5点经验。
- 生命值降至0时结束整局；本局经验、等级与构筑后的卡组不继承到新局。

### 5.1 初始卡组

初始卡组共10张牌，包含3种卡牌：

| 卡牌 | 数量 | 能量费用 | 效果 |
|---|---:|---:|---|
| 打击 | 5 | 1 | 造成6点伤害 |
| 防御 | 4 | 1 | 获得5点格挡 |
| 整备 | 1 | 1 | 抽2张牌 |

### 5.2 升级选牌池

升级选牌池包含7种卡牌：

| 卡牌 | 能量费用 | 效果 |
|---|---:|---|
| 重击 | 2 | 造成15点伤害 |
| 连击 | 1 | 连续造成两次4点伤害 |
| 盾击 | 1 | 造成等于自身当前格挡的伤害，不消耗格挡 |
| 固守 | 2 | 获得12点格挡 |
| 迅击 | 1 | 造成5点伤害，抽1张牌 |
| 战意 | 1 | 本回合每段攻击伤害增加2点，可叠加，回合结束清除 |
| 稳守 | 1 | 获得4点格挡，抽1张牌 |

每次升级从上述7种牌中随机提供3种不同的牌，各种牌等概率抽选。卡组允许同名牌重复，后续升级可以再次选择已拥有的牌。

第一版共10种卡牌：3种初始牌加7种升级候选牌。防御进攻方向使用格挡配合盾击，连续攻击方向使用战意配合连击。

### 5.3 卡牌阶段范围

- 第一版暂缓卡牌强化、卡牌移除与卡牌稀有度分层。
- 卡牌稀有度暂缓不影响背包物品的稀有度和带出结算排序。

### 5.4 经验曲线与升级效果

- 当前等级为 `L` 时，升下一级需要 `20 + 10 × (L - 1)` 点经验。
- 升级时扣除所需经验，多余经验保留，用于下一次升级。
- 1→2级需要20点经验，2→3级需要30点，3→4级需要40点，之后按公式递增。
- 一次结算可以连续升级，逐次升级并每级分别进行一次三选一，可跳过。
- 升级仅获得选牌机会，不增加属性，也不恢复生命。
- 第一版不设置等级上限。
- 失败获得的5点经验仅计入本局结果统计，直接进入失败带出结算，不再弹出升级选牌，也不继承到新局。

## 6. 已确认：卡牌战斗基础

- 初始生命值为60，初始最大生命值为60。
- 玩家先行动，然后敌人行动，交替进行。
- 出牌以能量支付费用。
- 玩家每回合开始时将能量重置为3，剩余能量不累积到下一回合。
- 玩家每回合开始时抽5张牌，第一回合也抽5张。
- 结束回合时弃掉剩余手牌。
- 抽牌堆耗尽时，将弃牌堆洗回抽牌堆，继续完成剩余抽牌。
- 攻击伤害先抵消目标格挡，再扣除目标生命；连击逐段结算。
- 各单位的格挡保留到其下一个回合开始，然后清零。
- 第一版每场战斗只有1个敌人，可以有不同敌人类型。
- 新战斗开始时沿用当前生命，将本局卡组重新洗成抽牌堆，手牌、弃牌堆与格挡清空。
- 在玩家行动前显示敌人下一次行动意图及数值。
- 生命值跨战斗保留，胜利后的后续战斗沿用战后生命值。
- 战斗胜利和失败均结束战斗并结算经验。
- 玩家生命值降至0时，整局游戏失败并结束，不返回探索继续。
- 生命恢复通过仅探索时可用的治疗药剂处理，具体规则见第7.2节；结果界面的信息见第7.3节。

### 6.1 角色与敌人

第一版采用1名角色、2种普通敌人和1个固定首领。

| 敌人 | 生命 | 行动循环 |
|---|---:|---|
| 洞穴蝠 | 18 | 每回合攻击，造成5点伤害 |
| 岩甲虫 | 30 | 获得6点格挡 → 攻击造成8点伤害 → 重复 |
| 首领：岩洞守卫 | 80 | 攻击造成8点伤害 → 获得10点格挡 → 攻击造成14点伤害 → 重复 |

- 每个敌人在自己的回合执行一个行动，从表中第一项开始，循环进行。
- 每个普通敌人独立以50%概率选为洞穴蝠或岩甲虫，同一地图允许出现两只同类。
- 第1～4张地图的同类敌人数值一致，第一版暂缓随地图加难。
- 第一版暂缓敌人的增援、回血、异常状态与首领阶段变化。
- 敌人意图显示明确数值，例如“攻击8”“格挡10”。

### 6.2 战斗界面与卡牌结算

| 项目 | 规则 |
|---|---|
| 出牌操作 | 左键点击手牌直接使用；攻击牌默认作用于唯一敌人，防御和辅助牌作用于自身 |
| 能量不足 | 卡牌不可使用，显示所需能量，手牌和能量保持原状 |
| 已使用的牌 | 先离开手牌，按描述顺序结算效果，全部完成后进入弃牌堆 |
| 抽牌不足 | 洗回弃牌堆后继续抽，两堆都空时只获得实际能抽到的数量 |
| 结束回合 | 点击“结束回合”，弃掉剩余手牌、清除战意，再执行敌人行动 |
| 操作时机 | 仅玩家回合可出牌，牌效结算或敌人行动期间暂停出牌输入 |
| 战斗胜利 | 敌人生命归零时立即结束战斗，结算经验和升级选牌，然后返回探索 |
| 战斗失败 | 玩家生命归零时立即进入整局失败流程 |
| 查看牌堆 | 抽牌堆可查看卡牌组成，不显示顺序；弃牌堆可查看具体内容 |

- 每次玩家回合开始，依次清除自身格挡、将能量重置为3、抽5张牌，再开放操作。
- 敌人回合先清除自身格挡，再执行当前意图。
- 战斗界面显示双方生命与格挡、玩家能量、手牌、两个牌堆数量、敌人意图和“结束回合”按钮。
- 第一版暂缓拖拽出牌与复杂动画。

## 7. 已确认：地图、背包、结算与存档

### 7.1 短流程与随机地图

- 第一版共5张地图：第1～4张为随机常规地图，第5张为固定首领地图。
- 短流程采用第一区域规则，常规地形以房间结构为主。
- 第1～4张常规地图统一为25×25格，每格1个Unity单位。
- 地形采用多个矩形房间与连接走廊，包含环路，让地形形成独立墙群。
- 每张常规地图9个矩形房间，分布于3×3个布局区；房间宽、高各随机3～5格，横纵位置在各区中心附近最多随机偏移1格。
- 走廊宽1格，连接横向和纵向相邻房间形成环路，拐弯方向随机。
- 最外层一圈墙负责封闭边界，不能破坏。
- 随机地形生成、验收与必要时重新生成属于第一版必做内容。
- 基础地图须地面四方向连通、至少4个独立墙群，且至少2个墙群各含完整的内部 `3×3` 墙块。
- 隐藏门从自然生成的合法墙格中选择，遵循门候选和门间距离规则，不为门额外构筑墙体。
- 无法安排必要门时重新生成基础地图。
- 单张地图最多尝试生成100次，仍不合格则提示生成失败并返回菜单，不放宽验收规则。
- 每张常规地图均安排前进门，第3张额外安排返回门；门在基础地形验收完成后分配。
- 基于本局Seed生成随机结果；新局重新生成，存档恢复沿用原结果。
- 开始新局时一次性生成4张常规地图，进入下一张时不再重新生成。
- 第3张常规地图提供隐藏返回门；第1、2、4张常规地图不安排返回门。
- 第5张固定首领地图为13×13格，无迷雾，玩家与首领使用固定位置；击败首领后出现直接显示的返回门，不使用常规隐藏门候选算法。
- 第5张地图不存在前进门，击败首领后不会自动结束本局。
- 返回门继续提供“存档／结束游戏”选项；第5张首领击败后，选择“结束游戏”并完成带出结算，才记为本局胜利。
- 第5张首领击败后选择“存档”，保存首领已击败的本局状态，暂不正式结束，也不结算胜利；继续本局时恢复该状态。
- 此短流程为模型阶段规则，不替换完整版60层流程。
- 常规地图玩家出生点从可用地面格随机选择，沿用原规则。
- 随机地图、战斗洗牌与升级选牌使用分别保存的随机序列，避免战斗操作改变其他地图的生成结果。
- 点击寻路采用四方向网格路径，人物沿路径连续移动；键盘斜移不能穿过墙角。
- 首领场地内部为开放地面，四周一圈边界墙。坐标以地图左下角为 `(0,0)`：玩家 `(6,2)`、首领 `(6,9)`；击败后遗物位于 `(6,9)`，返回门位于 `(6,10)`。

| 模型地图序号 | 地图类型 | 返回门 |
|---|---|---|
| 1 | 随机常规地图 | 无 |
| 2 | 随机常规地图 | 无 |
| 3 | 随机常规地图 | 隐藏返回门 |
| 4 | 随机常规地图 | 无 |
| 5 | 固定首领地图 | 击败首领后出现 |

### 7.2 背包与物品

- 第一版包含常规背包与离局用可变背包，采用地图文档第14节规则。
- 常规背包20格，同名物品每格最多堆叠20件。
- 离局用可变背包不堆叠，每件物品独立占1格，仅在正式离局时用于结算。
- 第一版物品包含少量可收集物品与回血消耗品。
- 第一版共4种物品，稀有度顺序为：稀有＞罕见＞常见。
- 卡牌获取仍仅通过升级选牌，物品不提供额外卡牌获取途径。

| 物品 | 稀有度 | 用途 |
|---|---|---|
| 碎矿石 | 常见 | 收集并带出 |
| 晶簇 | 罕见 | 收集并带出 |
| 古代遗物 | 稀有 | 收集并带出 |
| 治疗药剂 | 常见 | 使用后恢复20点生命 |

- 新局常规背包初始为空。
- 治疗药剂仅在探索时可用，从背包中点击使用，每次消耗1件。
- 恢复不超过最大生命；满血时不能使用，也不消耗药剂。
- 拾取优先补满同名物品堆叠，再使用空格，每格最多20件。
- 空间不足时能放多少就拾取多少，剩余物品留在地面。
- 允许选择数量丢弃，丢弃物品留在当前地图地面，可重新拾取。
- 每件物品分别记录首次获取时间；丢弃再拾取不刷新，供失败结算排序。
- 物品生成数量和位置规则见第7.5节；地面物品通过左键点击后接近交互，或在交互范围内高亮后按 `E`拾取，具体操作见第2.1节。

### 7.3 离局结算

- 短流程统一采用第一区域容量：主动离开可带出10件，失败可带出5件。
- 主动通过返回门选择“结束游戏”后，由玩家自行选择带出物品，数量不超过10件。
- 生命值降至0，整局失败，按被动离开规则自动选择最多5件物品。
- 被动选取优先稀有度更高的物品，同稀有度优先首次获取时间更晚的物品；两者相同则首次入包顺序更晚的物品优先。丢弃再拾取不刷新首次获取时间和首次入包顺序。
- 正式结束本局时执行带出结算；通过返回门选择“存档”不执行带出结算。
- 第5张首领击败后通过返回门选择“结束游戏”，使用主动离开的10件带出容量；完成结算后记为本局胜利。
- 第3张返回门选择“结束游戏”属于普通主动离开，不记为本局胜利。
- 带出候选只来自当前常规背包，地面物品需先拾取。
- 主动离开可手选0～10件，不要求装满；每件独立占1个带出格。
- 主动选择带出物品时，确认前可取消并返回探索；确认后完成结算。
- 失败离开自动选择最多5件并展示结果，玩家不能更换带出内容。
- 未带出物品在本局结束后不保留。
- 结果界面显示胜利／主动离开／失败、到达第几张地图、最终等级、获得的经验和带出物品清单。
- 结算完成时，将带出物品存入局外仓库，清除该局待恢复存档，再返回局外入口。

#### 局外仓库与入口

- 仓库按物品种类累计数量，第一版不设容量上限，写入磁盘保存。
- 新局常规背包仍为空，第一版暂缓从仓库携带物品入局。
- 局外入口采用简单菜单，提供开始新局、继续存档、查看仓库和退出。
- 完整世界地图放到后续阶段。

### 7.4 存档恢复

- 第一版包含写入磁盘的存档与恢复，沿用“返回门 → 存档／结束游戏”流程。
- 选择“存档”保存完整游玩状态，本局暂停并保留，不执行带出结算。
- 继续本局时恢复原Seed、随机结果、玩家位置、生命、经验、等级、卡组、背包和各地图状态。
- 地块揭示、墙体破坏、敌人结果、门、物品与首领状态均须保留。
- 继续已存档本局时不得重新Roll地图或对象随机结果。
- 保存地图结果与随机进度，继续后不改变后续随机结果。
- 第一版只保留1个可继续的本局存档，仓库数据独立保存；继续入口位于局外菜单。
- 手动保存地点为第3张返回门，以及第5张击败首领后的返回门。
- 保存成功后返回局外菜单；保存失败提示原因，玩家留在当前地图。
- 已有本局存档时开始新局，提示将放弃旧局；确认后清除旧局存档，不执行带出结算，仓库保留。
- 普通探索中直接退出不额外存档；下次只能恢复最近一次手动存档，没有存档则只能开始新局。
- 死亡或主动确认结束本局时，旧的探索存档立即失效，不能恢复到结束前。
- 结算中退出，下次接着完成未完成的结算，不能重复入库；主动结算尚未确认时仍可取消，回到进入结算前的探索状态。
- 存档采用本地JSON，保存完整地图与对象结果、玩家状态、各随机序列状态与未完成结算。
- 地图、战斗洗牌和升级选牌的随机序列分别保存；具体Seed派生函数与内部数据结构属于实现细节，需验证继续游戏时原结果和后续随机进度保持一致。

### 7.5 敌人与物品分布

第1～4张地图采用相同的基础数量：

| 对象 | 每张常规地图数量 |
|---|---|
| 普通敌人 | 2个，类型从敌人池随机选择 |
| 碎矿石 | 3堆，每堆随机2～4件 |
| 晶簇 | 2堆，每堆随机1～2件 |
| 治疗药剂 | 2处，每处1件 |
| 古代遗物 | 每张地图独立有25%概率生成1件 |

- 敌人与物品随机放置在可用 `Ground` 上，初始不重叠，也不占玩家出生格。
- 常规地图对象的类型、数量与位置在新局生成时确定，之后保存状态，不刷新。
- 普通敌人战胜后移除，只奖励经验，不掉落物品；物品通过地面拾取获得。
- 第5张地图只放首领，击败后生成1件古代遗物供玩家拾取，再通过返回门存档或离局。
- 打完全部8场普通战斗可获得80点经验，在进入首领战前完成两次升级选牌。
- 普通敌人池与首领行为见第6.1节，普通敌人独立等概率选为洞穴蝠或岩甲虫。

## 8. 优先实现建议

下列为实施建议，不代表所有范围和数值已经确认。

| 顺序 | 内容 | 需要验证的结果 |
|---|---|---|
| 1 | 随机地图生成、验收、Seed与本局状态 | 每张常规地图满足地形和必要门约束，随机结果可用于存档恢复 |
| 2 | 连续移动、双输入切换、墙体碰撞、2.5D跟随摄像机、基础迷雾 | 人物能探索，墙体与边界可辨认，键盘能够打断寻路 |
| 3 | 破墙、隐藏门、前进与地图切换 | 玩家能通过探索找到门并继续前进，切图保留状态 |
| 4 | 独立卡牌战斗、敌人意图、胜负判定、胜利后返回 | 胜利后返回探索并保留状态，生命降至0时进入整局失败结算 |
| 5 | 战斗经验、等级、三选一或跳过、卡组查看 | 新卡进入卡组并影响后续战斗，胜负经验均按规则发放 |
| 6 | 常规背包、拾取、丢弃、回血物品 | 物品按格数和堆叠规则入包，探索时每件药剂恢复20生命，丢弃保留物品首次获取时间 |
| 7 | 主动与失败带出结算、短流程完成、新局重置 | 主动手选最多10件，失败自动选最多5件，新局重置成长 |
| 8 | 返回门存档、局外继续入口、磁盘恢复 | 重启后恢复本局随机结果与完整状态，存档不触发带出结算 |

探索与战斗切换至少需要保留位置、地块揭示、墙体变化和敌人结果。本局状态的内存保留应先于写入磁盘的存档功能。

摄像机应优先验证人物、敌人和门的可见性，以及连续移动时墙角不会被穿过。遮挡处理按已确认规则实现，并在试玩中检查半透明墙、碰撞与迷雾的效果。
