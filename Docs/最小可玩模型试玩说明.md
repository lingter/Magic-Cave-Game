# 最小可玩模型试玩说明

日期：2026-10-18。玩法制作基准为《最小可玩模型范围_v0.1.md》。原型已改为固定正交像素画面，接入现有16×16素材。

## 启动

Unity编辑器打开 `Assets/Scenes/MagicCavePrototype.unity`，按Play，点击“开始新局”。需要重建场景时可使用菜单 `Magic Cave → Create Playable Prototype Scene`。

像素版Windows运行文件为 `Builds/WindowsPixel/MagicCaveGame.exe`。分享或移动时保留整个WindowsPixel目录，包括 `MagicCaveGame_Data`、`UnityPlayer.dll` 和运行库目录。`Builds/Windows` 保留此前的3D占位版本。

## 种子测试

局外菜单点击“随机种子”切换到“自定义种子”，点击输入框填写32位整数，再开始新局。支持0、负数以及 `-2147483648` 至 `2147483647`。可使用Backspace删除、Delete清空、Ctrl+A清空后重填，以及Ctrl+V粘贴。

默认关闭自定义种子，每局生成新种子。每局开始时输出 `[MagicCave] Run Seed = 数值`，探索HUD同时显示Seed。继续存档输出 `[MagicCave] Continue Run Seed = 数值`。Windows输出记录在Player.log。

相同种子在同一程序版本下生成相同的四张常规地图、初始对象与独立随机流。战斗洗牌、升级选牌分别使用独立随机流；要复现后续战斗和选牌，需要使用相同的战斗及选牌操作顺序。拾取时间和本局唯一标识不由种子决定。存档保留随机流的当前位置，继续游戏不会重新生成地图。

推荐测试种子 `12345`：第1张地图出生格为 `(2,13)`；规则测试已用此种子完成八场普通战斗、首领战、升级构筑、药剂使用、第3张图存读档和最终10件物品带出。

## 操作

| 操作 | 效果 |
|---|---|
| WASD / 方向键 | 按屏幕方向自由连续移动，键盘输入打断自动寻路 |
| 左键地面 | 在已揭示区域内四方向寻路 |
| 左键敌人、物品或门 | 自动接近至交互距离并操作 |
| E | 操作附近高亮对象，鼠标指向的附近对象优先 |
| 右键内部墙 | 自动接近后破坏一格；边界墙不能破坏 |
| B / 背包按钮 | 查看20格背包，探索时使用药剂或选择数量丢弃 |
| Tab / 卡组按钮 | 查看本局卡组 |
| Esc | 关闭背包或卡组等面板；否则暂停 |
| 左键卡牌 | 支付能量并出牌；能量不足时不可使用 |
| 结束回合 | 弃掉剩余手牌，敌人按显示意图行动 |

角色靠近敌人不会自动战斗。存活敌人有实体体积，所在格不能进入，点击敌人会停在相邻格开始战斗；战胜后该格恢复通行。可绕行或破墙选择路线，前进门不要求清图。地图门藏在墙内部；门四方向相邻的墙探索揭示后会呈金黄色，鼠标指向时提示“门的线索”，可据此右键破墙寻找门。未揭示的墙不会透过迷雾高亮，发现过的门会持续可见。敌人与物品首次发现后都持续显示，离开当前视野也不隐藏；未发现对象仍由迷雾遮住。敌人战胜后移除，物品随拾取等玩家操作更新。

镜头正对XY地图平面，采用正交投影并随角色平滑移动，不允许旋转和手动缩放；鼠标中键拖动与 Shift+R / Shift+T 不控制镜头。每格16像素、1单位，运行时选择整数像素放大倍数。切图、战后返回、读档和新局均保持相同朝向，旧存档中的镜头方位会被忽略。

玩家碰撞为0.8×0.8格，墙体、存活敌人和地图上的箱袋容器均阻挡通行；拾取后对应位置可以通过。背包丢弃物为可踩过的小型地面掉落，仍可重新拾取。旧存档如果位于扩大的碰撞边缘或物品容器内部，读取时移至最近的可站立地面，原始文件保留。

## 素材适配

- 玩家使用 `Player_Down`、`Player_Up`、`Player_LeftAndRight`，向左移动时镜像侧面素材。
- 三张地板按坐标固定混排，不消耗地图随机序列。墙体按八邻格选择原墙块或组合现有墙纹，支持随机厚墙和破墙后的连接更新。
- 敌人暂映射为 `Enemy_2`、`Enemy_6`、`Enemy_9`，沿用原有洞穴蝠／岩甲虫／首领的规则名称和数值；可在素材配置中替换。
- 碎矿石、晶簇以装备箱表示（晶簇偏蓝），遗物以宝箱表示，药剂以补给袋表示；悬浮文字和操作提示说明实际内容。前进／返回门共用楼梯素材，以颜色和文字区分。
- 配置入口为 `Assets/MagicCavePrototype/Resources/PrototypeArt.asset`。原始Aseprite文件保留，显示使用共享的导出PNG。
- 独立10×10验证场景继续保留，正式可玩原型仍使用原有五张地图、战斗、背包和存档流程。

## 存档与结束本局

第3张地图有隐藏返回门；第5张地图击败首领后出现返回门。返回门提供“存档并返回局外”与“结束游戏”。存档不进行物品结算，首领战后存档也不直接判为胜利。

如果首领战后返回门出现在玩家脚下或与玩家体积重叠，玩家会移到最近的可站立位置，可继续移动并与门交互。旧版存档如果保留了玩家与存活敌人或首领返回门重叠的位置，新版读取时会修正到附近的可站立位置，不覆盖原始存档文件。

主动结束可以选择最多10件物品，确认前可取消回到探索。生命归零则整局失败，按稀有度、首次获取时间和入包顺序自动带出最多5件。只有击败首领后完成主动结算才记为胜利。物品确认入库后永久留在局外仓库，下一局背包为空，等级和卡组重置。

普通暂停返回局外或退出，只保留最近一次返回门手动存档。待结算状态写入磁盘，可以退出后继续；已确认的物品不会重复入库。开始新局会提示放弃已有存档。

本地数据位于 `Application.persistentDataPath/magic-cave-prototype`，Windows默认路径：

`%USERPROFILE%/AppData/LocalLow/DefaultCompany/Magic Cave Game/magic-cave-prototype/`

`session.json` 保存本局与待结算状态，`warehouse.json` 保存仓库；该目录上一级的 `Player.log` 记录Windows运行输出。编辑器与Windows包使用相同默认数据目录，测试前注意所选存档。
