## 已按本次要求落实

- 世界地图属于局外，独立于五张探索地图。传送门位于地图中上方。
- 草地原图按 16×16 切分，利用已有边缘及内部像素拼成连续整块地面；不重绘、不改色，Point 过滤、无压缩、无 MipMap。
- 帐篷是可进入的战士公会入口。内部会长在左、导师在右、财宝存储箱在中后方、出口在下方；位置经用户授权自由安排。
- NPC 原图：左上为会长、右上为导师、下半部为仓库财宝存储箱。头顶只显示名称，走近后才显示功能与交互事项。
- WASD / 方向键移动；左键地面寻路；左键人物或建筑自动接近交互；E 与近处对象交互；Esc 关闭面板。键盘移动会取消寻路。
- 公会开放骑士职业。导师提供树状天赋，会长提供公会升级，仓库提供库存、出售、捐赠和扩容。

## 存档与容量

- 金钱、声望、公会等级、天赋和库存保存在原 `warehouse.json` 中，格式升级至 v2；继续使用原存档目录，不覆盖旧探索存档。
- 旧无限仓库迁移时保留所有库存和已结算记录，基础容量至少覆盖原有库存；不会清除超出初始 100 件的旧物品。
- 出发时把天赋效果写入本局快照。之后回城学天赋、重置天赋再继续存档，本局仍使用出发时的属性。
- 正式结算的物品、金币、声望使用同一局 ID 入账记录，中断后重试不会重复获得。
- 仓库满时先保留结算，可从结算页面进入仓库出售或扩容，再回来入库；不静默丢失选中的物品。
- 当前仍遵循原型规则：新局背包为空，不从局外仓库取物。
